I’m a final-year Computer Science student at SNGCE. I specialize in building web and mobile applications, and I am

## Projects

### Local Workforce Platform *(in development)*
- **Tech Stack**: React, Next.js, Flutter, Supabase, Tailwind CSS
- Description: A platform for event, hospitality, and logistics teams to find temporary staff. Currently working
on role-based access, shift matching by proximity, and identity checks.

### SpendStudent
- **Tech Stack**: React, Supabase, Dexie.js, Tailwind CSS
- Description: An offline-first student expense tracker. Syncs browser data with PostgreSQL and uses row-level
security to keep user data separate. Resolved startup loading issues to prevent a flash of incomplete UI.

### Smart Yatra
- **Tech Stack**: Flutter, Dart, Firebase Realtime Database
- Description: A campus fleet tracking app. Adjusts how often a vehicle sends its location based on speed,
reducing unnecessary GPS use and database writes.

### Smart Voting System
- **Tech Stack**: Python, Next.js, MongoDB
- Description: A voting system project combining computer vision for identity checks with a web interface and
transaction logging.

### Interactive 3D Portfolios
- **Tech Stack**: Astro, React, Tailwind CSS, Spline, Vercel
- Description: Portfolio sites with embedded Spline scenes. Astro's selective hydration helps keep the rest of the
page responsive while 3D content loads.
